## 陷阱囚牢的规矩（2026-11-06 实测）

- **只有队长点瓶子才算**：组队时队员点瓶子没反应；队长拿到结晶，五个人身上同时都有，任务进度也一起走。
- 点瓶子不弹对话框。**对的瓶子每轮重新分配**，同一轮里错的一直错，所以每个瓶子点一次就够。点之前队长要站稳；点完看结果：有结晶 = 对；坐标跳走（被传到门口）= 错；原地没动也没结晶 = 扣血，错；马上进了战斗 = 走路遇怪把这一下打断了，不算，打完原地重点（遇怪是走路引起的，不是瓶子的惩罚）。这一轮点错过哪些存在 `batch_provision/runtime/boss_gear_5_touched.json`，中途重跑不会重点。
- 琉璃瓶「召唤鹰王战斗」：第一次选会弹 boss 题（答题器自动答），答完再选一次才开战。鹰王约 90 秒打完，五人任务都算过。

研究用的小脚本：`probe_bottle.py`（走过去点一个 NPC，记录结果）、`probe_member.py`、`probe_team_loop.py`。
