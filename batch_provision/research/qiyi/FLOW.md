队1（5 个 74–76 级号，2026-10-28 12:28 打开，不是用我们的启动器开的）：

## 跑法

```bash
python -X utf8 research/qiyi/go.py 飞天把你射成蜂窝 舔尊 西域霪欲魔 睿睿猪 辰汐            # 到 星灵神域 (默认)
python -X utf8 research/qiyi/go.py --to 3110 飞天把你射成蜂窝 舔尊 西域霪欲魔 睿睿猪 辰汐  # 只到 永冻群山

```

先给每个窗口注入 DLL 并开录包（`research/shitu/attach_tap.py`，已注入的只补 arm），然后 5 个窗口同时跑。
路线是 `go.py` 里的 `ROUTE` 表，每张地图一行（站点、NPC、选项、去哪）；加一步 = 加一行。从路线上任何一张图开始都能接着跑。

## 踩过的坑

- 寻路刚到出口、还没跨图时，`nav_active` 会先变 0。第一版脚本这时又发了一次寻路，结果号跨到了 map 25，但寻路标志一直是 1，
  卡在 (2982,1563) 不动。现在：站在出口 30 px 内只等；寻路标志为 1 但 5 秒没动就取消。两条都有单元测试
  （`tests/test_qiyi_go.py`；领薪水的规则在 `tests/test_qiyi_salary.py`）。
- 野外遇怪：战斗中位置不变，寻路标志还是 1。如果按「5 秒没动就取消」，每场战斗后都会取消再重走，3 次后脚本会以为卡死。
  现在「没动」从上一场战斗结束时算起；角色走动过就把「同一动作重复」的计数清零。单次超时从 300 秒放宽到 600 秒。
- 许愿页同一个选项要连选 8 次，原来的「同一动作连续 3 次没效果就停」会误停。现在对话框文字变了（计数变了）也算有效果。
- 注入的 DLL 卸不掉，关窗口才会消失。答题器同时在跑，没有冲突。
