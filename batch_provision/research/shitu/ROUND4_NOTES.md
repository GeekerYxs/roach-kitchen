## 后段出过的问题和改法（都已改进脚本）

| 现象 | 根因 | 改法 |
|---|---|---|
| 徒弟「邀请 4 次都没进队」，距离只有 54 px | 服务器回 0x46ff「与邀请者之间有障碍」 | `teamwalk.regroup`：邀请失败后师傅走到徒弟脚下再邀请；徒弟 60 s 走不到时师傅走过去 |
| 拾取情报 / 拿树上日记 / 拿花露瓶 后任务步数不变 | 路上打怪掉落把背包塞满（「物品栏已满！」），任务物品没进包 | `team_npc.talk` 和 `scorpion_king` 每次对话 / 开战前 `r4_util.space_one(c, 2)`；`tower1_go.bottle()` 缺花露瓶自动回 304 补 |
| 蝎子王打完只有 0–1 人拿到蝎爪 | 同上（背包满） | 开战前清格；没拿到的再打一次，**由没蝎爪的徒弟当队长**（有蝎爪的队长 BOSS 会说「走开」） |
| 采花露重跑时一直空转 | 重跑从 0 计数，花对已采满的号不再给 | 背包有 花露瓶(10692) 就算 5 滴 |
| 拳手 40 个早已杀够，重跑等了 44 分钟 | 系统消息只发一次 | `quan100` 记 state `kills40`，重跑跳过 |
| 古迹里寻路原地重试 300 次 | 伏地魔2 卡在 650 (3840,2944) | `maze_train` 同一处连续卡 20 次就停，交给监管器回城重来；`guji_entrance` 人已在古迹里先回城 |
| 落单徒弟在沙漠里打怪，回城一直等 | 回城只等战斗结束 | `quanshou.flee`：非队员先逃跑再用回城卷；集合时队长遇怪也逃跑 |
| 师傅回城卷用光 | 每次全队回城每人 1 张 | 回城后师傅不足 10 张就去铁公鸡补到 60；没卷时向身边徒弟借 5 张 |
| 某徒弟任务落后好几步没人发现（亿万13 停在 181 第 4 步） | 每步只打印进度 | `r4_util need QID N`：后段每步末尾检查全员步数，没到就报错 → 监管器重跑该步 |
| 改 shell 脚本把正在跑的队搞乱（exit 127） | bash 按字节偏移读脚本 | r4_early/mid/late、r4_supervise 整段 `{ … exit }` 包起来；见 memory feedback-running-bash-edits |

单人补跑：`SHITU_APPRENTICES=亿万7 FROM=corpse UNTIL=corpse bash r4_late.sh`（UNTIL = 跑完这一步就停）。
排除某个号：`SKIP=亿万13 bash r4_sup.sh d late q183`。
