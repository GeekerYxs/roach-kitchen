原始数据：

## 1. 一句话结论

- **采集物就是 NPC**。采集和 NPC 对话完全一样：
  - 先点它，发 `0x0050`；
  - 服务器回一个对话框 `0x4019`，只有一个选项「采集遗忘之花」；
  - 再选这个选项，发 `0x0051 opt=1`。
- **没有读条**。选完以后约 60 ms，服务器就把物品发到背包里。
- **每朵花采完后要等 3 分钟才能再采**。
- **遗忘之石靠「暗·遗忘之花」拿**：采暗花基本都会被伏击，打赢后掉 1 个遗忘之石。

类比：每朵花就像一个只会说一句话的 NPC，「点它 → 选『采集』」等于「找它说话 → 选第 1 句」。暗花像一个藏着强盗的摊位，你一伸手就被拉去打一架，打完强盗身上掉石头。

## 2. 任务

这一步在任务表里是「遗忘洞穴的恐慌」，任务 224。数据来自 `Tasklib/SubTask_utf8.csv` 和 `PhaseTask_utf8.csv`。

- 先在遗忘洞穴采到至少 **9 朵遗忘之花 + 3 颗遗忘之石**，才能挑战地头蛇（NPC 1172，map 750 (4014,7869)）。
- 地头蛇在「蛇王卧室」里，入口是 NPC 10214 (3306,6183)，出口是 NPC 10215 (4287,8223)。
- 如果组队挑战，**每个队员都要接这个任务**；战斗中逃跑算任务失败。
- 打赢后回龙之都外城，找大个王 (4398,2553) 交任务。

内存【已确认】：欧皇的任务 224 是进行中，steps=(1,)，`world.read_quest(mem, 224)`。

### 4.2 `0x4020` 背包格更新（24 字节）【部分确认】

```
+0  u32 char_id
+4  u16 3c00（每次都一样）
+6  u16 0100
+8  4 字节，每次不同（02a10100 / 0203701f / 02b50200 / 02000000 …），意义不明
+12 u32 物品 id（8e2b0000 = 11150；8f2b0000 = 11151）
+16 u16 0100, u16 0100
+20 u16 背包格号
+22 u16 这一格现在的数量
```

遗忘之石第一次到手时 `0x4020` 是 `… 8f2b0000 0100 0100 3a00 0100`：第 58 格，数量 1。

## 5. 自动采集（`gather.py`）【已确认，实跑成功】

```
python -X utf8 research/shitu/gather.py 欧皇 20          # 遗忘之花采到背包里 >= 20 朵
python -X utf8 research/shitu/gather.py 欧皇 6 dark      # 采 6 次暗·遗忘之花，先采离蛇王卧室入口最近的 6 朵
python -X utf8 research/shitu/gather.py 欧皇 9 && python -X utf8 research/shitu/gather.py 欧皇 3 stones
                                                          # 一个地头蛇门票：先采 9 朵花，自动换到下层，再采到 3 颗石头
```

每一轮的流程：
1. 读背包，`world.read_bag` + `item_count(11150/11151)`；够数就结束。
2. 正在战斗（`read_world().in_battle`）就一直等它结束。用户开了自动技能，脚本自己不出招。
3. 在还没采过的花里，选离自己最近的一朵（贪心「最近邻」路线）。用官方寻路 `Game.navigate(750, x, y)` 走过去。
   - 路上被拉进战斗就等打完；
   - 4 秒没动就重新寻路。
4. 走到 80 px 以内并停下后，调 `ClickNpc(npc)`，然后读内存里的对话框。
   - 对话里有「刚刚采过」→ 选 0（离开），记为冷却中；
   - 有含「采集」的选项 → `SelectDialog(opt)`；
   - 等背包数量变化或进入战斗。伏击战打完后再读一次背包。
5. 所有花都采过时，回到最早采的那朵；不到 185 s 就原地等到满 185 s（这次没用上）。

实跑结果：
- 遗忘之花：22:46:14 → 22:55:01，背包里 4 → **20**，一共走了 17 朵花（4198 在冷却中被跳过）。
  - 期间打了 48 场战斗，都是路上的随机遇怪，自动技能打完的。
  - 全程只调用游戏函数 + 读内存，没有点 UI。
- 暗·遗忘之花：22:58:52 → 23:04:44，采了 6 次，背包遗忘之石 0 → **5**，遗忘之花 20 → 21。
  - 背包最后的读数是：遗忘之花 21，遗忘之石 5（第 58 格）。
