## 2. 人员和分工

- **师傅**：70 级，有扫射技能和带烈焰爆发的宠物。一个师傅最多带 4 个徒弟，组成 5 人队。
- **徒弟**：新建角色。第 3 轮用的账号是 mvp01–08 的第 2 个角色位，密码在 `local.toml` 的 `[accounts]`。
- **两队并行**：用 `SHITU_MASTERS`、`SHITU_APPRENTICES`、`SHITU_STATE` 三个环境变量各配一套（见 research/shitu/README.md）。
- **一个窗口同一时间只能有一个脚本在操作。**
- **录制**：`monitor.py --new <角色...>` 只读不发，内存变化写到 `logs/mem_*.jsonl`，网络写到 `logs/net_*.jsonl`。手动示范一次，就能照着录下来的包写脚本，出师、邮件都是这样做出来的。

## 6. 坑和处理办法（都是第 3 轮真遇到的）

| 现象 | 原因 | 处理 |
|---|---|---|
| 徒弟单独在野外走，战死（千万7、千万5、千万8） | 徒弟发逃跑不一定成功；通天塔一区、遗址的怪对单独的 40 级徒弟太强 | **野外永远师傅带队走**。徒弟只在目标旁边离队几步。队长到目标后再多走 80 像素（`past`），队尾的人就站到目标旁了 |
| 死了怎么办 | 身上有心脏起搏器会原地复活，有幸运丸不扣经验；没有就回逍遥村 | 规则：徒弟一死，全队停下等人决定。monitor 里看得到「心脏起搏器」「幸运丸」的提示 |
| 重新组队「接受 3 次都没进队」 | ① 两人中间隔着障碍（塔、藤蔓）；② 「上一个邀请人」还是这个师傅，接受发得比邀请早 | `dew_team.regroup`：徒弟先走到队长 80 像素内 → 邀请 → 等 1.5 秒再接受，最多 4 次 |
| 队员点 NPC 没反应 | 跟随中的队员点不了 NPC | 先离队再点；需要整队一起做的事（打蝎子王）让徒弟当队长 |
| 师傅停着不动，「寻路中」标记一直亮 | 客户端寻路卡死 | `lead_to` / `step_to`：站着不动 3 秒就取消寻路、重发 |
| 交易失败后两个人都动不了 | 「交易双方之一物品栏满」后，交易窗口还挂着，之后丢东西、用道具、飞鞋都没反应 | 交易前先确认双方背包有空格；真锁住了就手动关掉交易窗口（取消交易的包还没录） |
| 背包满（拿不到瓶子、情报、蝎爪） | 打怪掉落把背包塞满 | 每个阶段前保证 ≥3 个空格；丢最便宜的 0 品质杂物，或者回城卖一次 |
| 回城卷用光，徒弟被困在野外 | 每次回城扣 1 张，没盯着数量 | **出发前每人补到 20 张**（自由市场铁公鸡，buy_scroll.py）。实在没有就用飞鞋（1 小时冷却） |
| 打完仗队伍又自己往前走 | 停脚本时，师傅之前发的寻路还在继续 | 停脚本后给队长发一次「取消寻路」 |
| 网络断开 | 13:05 全部掉队，巡逻停了 | 重新组队（regroup），再接着跑 |
| 二层进不去 | 光站在入口上不触发 | 到了 (1428,924) 就点 NPC 10153 |
| 第 5 滴花露没被计数 | 第 5 滴的提示是「获得了1个花露瓶」「你已经采集了足够的花露…」，不是「已经采集5滴」 | dew_team 里加了这一句的判断 |
| 肉林吃完后血一直不满 | 肉林是战后自动回血的；吃完就不会自动回 | 用 0x40e0 读血量，`heal.py` 吃萝卜糕；野外段前多买萝卜糕（铁公鸡货架 0） |
| 0x46f5 反外挂题 | 打地头蛇 / 蝎子王「开打」时弹出 | `dts.py`、`scorpion_king.py` 调 `boss_quiz.solve`：先等答题器 4 秒，没答就自己答（题库 > 排除干扰项 > 猜），再重新点 boss；答错被踢下线 -> 脚本退出，产线关窗重登、整步重跑 |

## 7. 下一轮可以优化的地方

1. **路线**：
   - 龙之都 → 苦无沙漠一律走「PP鸡 → 恶人山 → 西出口」；
   - 逍遥村 ↔ 自由市场 / 梦幻岛走免费传送门；
   - 每个阶段开始前先算好回城卷，出发时每人 20 张。
2. **任务 181 / 183 少跑腿**：
   - 拿日记（无尽平原3区）和杀 40 拳手在同一张地图，可以一趟做完；
   - 看水晶和倒花露都在古迹二层，**可以先去通天塔采花露、拿瓶子，再一次进古迹**（要先在教头那里拿到瓶子，所以顺序是：教头 → 古迹看水晶 → 教头拿瓶 → 通天塔 → 古迹倒露 → 教头 → 龙格尔）；
   - 183 第 4 步的尸体和第 6 步的蝎子王都在遗址里，交情报那一趟没法省，但两趟都用「恶人山 → 遗址」，比走路快很多。
3. **串成一个流水线**：
   - 把第 4 节的命令写成一个 stage 表（像 maze_train 的 STAGES），每个 stage 记下「先决状态 → 执行 → 验收」，进度写进 state 文件；
   - 断了从断点续跑（参考 shitu_flow.py 的思路）。
   - 现在大部分 stage 已经是独立脚本，缺的是统一的调度和验收。
4. **背包策略统一**：
   - 每到城里就自动 `sell_tradable --stones`；
   - 每次出城前检查：空格 ≥5、回城卷 ≥5、血满（heal）。
5. **练级**：
   - 通天塔二区 31→40 要 85 分，是最大头；
   - 可以试试更高效的点，或者两个师傅都带满 4 个徒弟、早一点开打。
6. **录制先行**：遇到新 NPC 或新流程，先 `monitor.py` 录用户手动做一次，再写脚本。出师、邮件、买卖都是这样一次做对的。
7. **还没录的包**：取消交易、45 级礼包、45 级以后的任务。
