# 部署到另一台电脑（美味小强料理生产线）

一条线 = 5 个工位大号（调度员、古井队长、2 个海岸队长、收货人）+ 一个小号号段，约 42 个料理/小时。
32 GB 内存跑一条线（20 个小号窗口 + 5 个工位窗口）够用。

## 原则

- **每台电脑一个号段，绝不重叠。** 同一账号在两台电脑登录会互相挤下线。
  已分配：开发电脑 mw01–mw100，挂机电脑 mw301–mw360。下一台可用 mw361–mw420 等。
- **一条线要约 60 个账号**（240 个角色槽）：角色从新建到删除约 1–1.5 小时，删除后约 3.2 小时槽位才释放，
  42/小时 × 约 5 小时 ≈ 210 个槽，再留余量。
- **工位大号只能在一台电脑上在线。** 换电脑时先在旧电脑停掉总大脑、关掉工位窗口，再到新电脑登录。
  飞鞋记录点存在服务器上，换电脑不受影响。
- **每台电脑有自己的数据库**（`batch_provision/state/factory.db`），不拷贝、不同步。
  小号进度都是从游戏里实时读出来的；新电脑从空数据库开始，不会少任何东西。
- 只有 `local.toml` 是本机的（游戏路径、号段、全部密码），它不进 GitHub。其它配置是共用的。

## 新电脑第一次部署

1. 安装 **Python 3.14**（python.org，安装时勾选 *Add python.exe to PATH*）和 **Git for Windows**。
   不需要 pip 安装任何包。
2. 把游戏目录 `D:\什么什么大冒险2.0免安装绿色版2.97` 整个复制过去（约 2.4 GB），放在同样的路径最省事。
3. 拉代码：
   ```
   git clone https://github.com/GeekerYxs/roach-kitchen.git D:\roach-kitchen
   ```
4. 进入 `D:\roach-kitchen\batch_provision`，把 `local.example.toml` 复制成 `local.toml`，填好：
   - `[game] exe`：游戏路径；
   - `[accounts]`：本机号段（例如 start = 301、count = 60）和小号密码；
   - `[passwords]`：5 个工位大号的密码。
5. 双击 **`一键检查环境.cmd`**，所有项都是 `[OK]` 或 `[提示]` 即可。
6. 第一次使用新号段：双击 **`一键建角.cmd`**，给每个账号建 mwXXXr1–r4（每号约 30 秒，8 个窗口并行，60 个号约 5 分钟）。
   可以重复运行，只会补没建成的。报告在 `logs/provision_report_*.md`。
   如果某个号里有不是本工具建的旧角色，检查环境时会提示；那个号只用剩下的槽，不影响其它号。
7. 在旧电脑上停掉总大脑（黑窗口里按 Ctrl+C），并关掉 5 个工位窗口。
8. 新电脑双击 **`一键登录工位.cmd`**（5 个工位进游戏）。
9. 双击 **`一键总大脑.cmd`**。新角色会自动新手出村 → 古井 → 海岸 → 交料理 → 删除 → 3 小时后重建，一直循环。
   日志在 `logs/supervisor_*.log`，每分钟一行汇总。

## 更新代码

开发电脑改好并推送后，在挂机电脑上：先停总大脑，然后

```
cd /d D:\roach-kitchen
git pull
```

再双击 `一键总大脑.cmd`（它会接管已开的窗口接着做）。`local.toml`、`state/`、`logs/` 不受 `git pull` 影响。

## 不想在这台电脑跑了

停总大脑，关窗口，把 `local.toml` 里的号段换给下一台电脑（或换一批新号段）。
这台电脑上还没走完流程的角色就放着不管，以后可以删掉或换号段重新用（槽位释放后照常可用）。

## 长期挂机建议

- 电源选项设成“从不睡眠”，关闭“Windows 更新自动重启”。
- 关闭游戏和项目目录的实时病毒扫描（启动器会往游戏里注入 DLL，可能被误报）——在 Windows 安全中心里自己加排除项。
- 停机后再次双击总大脑，会自动接管还开着的窗口，从数据库里接着做。
